# Facebook Clone (UI Demo)

A working Facebook interface clone built with a single HTML file — HTML, CSS and vanilla JavaScript. No frameworks, no build step.

## Features
- News feed with posts
- Stories row
- Working post composer (your post appears in the feed)
- Like, comment and share interactions
- Live search

## Live Demo
https://raw.githack.com/ibrahimx305/Personal-portfolio/main/clones/facebook-clone/index.html

## Run it
Just open `index.html` in a browser.
